# Air Quality Prediction using Machine Learning

This project develops and compares machine learning models for predicting air pollutant concentrations using environmental sensor data.

## Models

- Support Vector Regression (SVR)
- Random Forest Regression
- Gradient Boosting Decision Trees (GBDT)

## Targets

- CO(GT)
- NOx(GT)
- NO2(GT)
- NMHC(GT)
- C6H6(GT)

## Key Techniques

- Data preprocessing
- Feature engineering
- Train/validation/test split
- Hyperparameter tuning
- Time-lag feature construction
- RMSE-based evaluation
- Model comparison

## Technologies

- Python
- NumPy
- Pandas
- Scikit-Learn
- Matplotlib
- Jupyter Notebook
